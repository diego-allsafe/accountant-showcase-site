# Accountant Showcase Website

Static multi-page website for a generic accounting firm.  
Built with semantic HTML, structured CSS, and clean project architecture.

## Project Structure

- `/html` → Website pages
- `/css` → Stylesheets
- `/js` → JavaScript files
- `/assets` → Images and static resources

This project focuses on clean structure, separation of concerns, and professional layout.
